个人知识库是 Agent 的受治理长期结构化知识存储。SQLite 是事实源，工作空间中的 `knowledge/` 目录只是机器生成的只读兼容投影。与按时间线组织的记忆不同，知识按主题组织，并具备版本、作用域、来源声明、审计和撤销能力。

## 核心概念

### 知识 vs 记忆

| 维度 | 知识库（knowledge/） | 长期记忆（memory/） |
| --- | --- | --- |
| 组织方式 | 按主题分类、互相关联 | 按时间线、日期文件 |
| 写入方式 | Agent 主动整理结构化内容 | 上下文裁剪时自动摘要 |
| 内容特点 | 提炼后的结构化知识 | 原始对话摘要 |
| 典型用途 | 学习笔记、技术文档、项目知识 | 对话历史、事件记录 |

### 只读投影

```
~/cow/knowledge/
├── index.md          # 自动生成的知识索引
├── log.md            # 自动生成的生命周期日志
├── concepts/         # 概念类知识
│   └── machine-learning.md
├── entities/         # 实体类知识（人物、组织、工具）
│   └── openai.md
└── sources/          # 来源类知识（文章、论文）
    └── llm-wiki.md
```

投影目录结构可以灵活组织，但禁止使用通用文件或命令行工具修改。创建和更新使用 `knowledge_write`，历史回滚和移除使用 `knowledge_rollback`、`knowledge_revoke`。

## 自动整理

知识库的写入是 Agent 的自主行为，在以下场景中触发：

- **用户分享文章或文档** — Agent 自动提取关键信息，创建结构化知识页面
- **对话产生有价值的结论** — Agent 将洞察整理为知识页面，并与已有知识建立关联
- **用户主动要求整理** — 用户可以通过对话指导 Agent 组织和更新知识

每个知识页面都包含与其他页面的交叉引用链接，逐步构建起一个知识图谱。

## 知识检索

Agent 在对话中通过受治理工具检索知识：

- **受治理检索** — `knowledge_search` 执行租户、用户、会话、集合和敏感级别过滤
- **核验读取** — `knowledge_get` 接收检索返回的完整 Citation v3 URI
- **Citation v3** — 每条 `knowledge://` URI 绑定不可变版本、证据字节范围、正文哈希、引文哈希和 `source_ref_hash`

引用 URI 必须逐字保留，禁止截断、调整参数顺序或手工重建。引用更新、撤销或版本不受支持时，应重新检索。`source_ref_hash` 只能证明已存储的来源声明没有变化，不能独立证明外部来源真实可信。

## Web 控制台

Web 控制台提供了专用的「知识」模块，支持：

- **文档浏览** — 树状目录结构，可搜索、可折叠，点击查看文档内容
- **知识图谱** — 可视化展示知识之间的关联关系，节点可直接跳转至文档
- **对话联动** — 投影 Markdown 文档链接可以跳转到文档浏览器；受验证的 `knowledge://` 引用通过治理工具解析

## CLI 命令

通过 `/knowledge` 命令管理知识库：

| 命令 | 说明 |
| --- | --- |
| `/knowledge` | 显示知识库统计信息 |
| `/knowledge list` | 以树状结构显示文件目录 |
| `/knowledge on` | 开启知识库功能 |
| `/knowledge off` | 关闭知识库功能 |

## 相关配置

| 参数 | 说明 | 默认值 |
| --- | --- | --- |
| `knowledge` | 是否启用个人知识库功能 | `true` |
| `agent_workspace` | 包含自动生成 `knowledge/` 投影的工作空间路径 | `~/cow` |
