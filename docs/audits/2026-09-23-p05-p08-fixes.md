## P07：CONFIRMED，修复验证通过

根因：Windows 冻结后端的 MIME 识别把 .md 返回为 application/octet-stream；Electron 资源窗口将其当下载响应，留下空白窗口。主界面 fetch 后解析 Markdown 不受此行为影响。不是中文 URL 编解码错误；英文名也复现。

修改：PreviewHandler 和 FileCapabilityHandler 在既有授权/路径约束之后，将 .md/.markdown 明确返回 text/plain; charset=utf-8，保留 nosniff。主界面继续安全富文本渲染；独立资源窗口显示 Markdown 源文本。没有新增协议或放宽 IPC/file 权限。

直接证据：`before-ui-links/results.json` 在实际 Markdown 链接点击中 14 条路径均返回 200 但窗口空白；`after-diagnostic` 和 `raw-diagnostic` 记录错误 MIME。新正式制品 `formal-p05-p07/results.json` 14 条路径全部正确显示内容，script 未执行，资源窗口没有 electronAPI。

文件名：test.md、测试.md、测试 文档.md、a b.md、中文 #100%.md、a&b.md、test[1].md；每项分别覆盖 preview 与 file capability 路径。`p03-p04-formal-final/results.json` 回归主界面 Markdown、允许内部链接、javascript/data/file 等拒绝及不可信窗口 IPC 拒绝。

验证等级：INTEGRATION_VERIFIED（新正式 win-unpacked）。
