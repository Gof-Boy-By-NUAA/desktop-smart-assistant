## 1. 执行摘要

当前项目是以开源 SmartAssistant 为基础，面向桌面智能体(Agent)运行时扩展的一套“受治理记忆、受治理知识、检索增强生成(RAG)、受治理技能与客户验收”实现。

基础 SmartAssistant 已提供多通道消息接入、模型适配、工具调用、记忆、知识库、技能、定时任务与自演化等通用 Agent Harness 能力。此工作树在其上增加了：

- 以 SQLite 事实库为核心的受治理记忆：租户、身份、权限、版本、幂等、审计、撤销、回滚及派生索引恢复；
- 受治理知识：UTF-8 字节级引用、文档版本、权限检索、撤销污染防护和兼容 Markdown 投影；
- 租户感知词法检索：FTS5/三元语法候选、权限过滤与事实源回查；
- 受治理技能：影子检索(Shadow Retrieval)、默认关闭的 Top-K 提示词注入、脱敏遥测、提案/评测/发布原语；
- 客户受控配对验收框架：固定输入包、签名执行证据、独立验证器与失败关闭状态。

**当前总体状态：未达到最终验收或生产启用条件。** 本次在当前工作树执行 `python -m pytest -q`，结果为 `742 passed, 3 failed, 38 skipped, 1 warning`。因此任何“全部持续集成(CI)通过”“检索基线已冻结”“技能生产注入可启用”的表述均不成立。

### 2.2 核心调用关系

```text
消息通道 / Web 控制台
  -> bridge.AgentInitializer
  -> Agent Loop（规划、模型调用、工具调用）
  -> MemoryManager / GovernedKnowledgeRuntime / SkillManager
      -> SQLite 事实库
      -> 可重建 Markdown 投影与 FTS5 词法索引
      -> 受身份、租户、作用域和敏感级别约束的查询结果
```

受治理数据采用“事实数据先提交，投影和索引为可重建派生数据”的设计。搜索结果在返回前回查事实库，因此撤销或旧版本索引残留会失败关闭(Fail Closed)。该设计与 `docs/rewrite/governed-memory-runtime-phase-2.md`、`docs/rewrite/governed-memory-transactional-outbox-phase-3.md` 的调用链描述一致。

## 3. 项目目标

本项目的可证实目标可分为四层：

1. **保持 SmartAssistant 原有智能体能力。** 不破坏既有通道、工具、模型、普通记忆/知识文件和 Agent Loop。
2. **建设可治理的本地 RAG 基础。** 将记忆、知识与技能的事实、权限、版本、撤销和审计从普通 Markdown/索引中分离出来，并让派生数据可恢复。
3. **在真实中文语料上验证检索与安全边界。** 使用 CMRC 2018 开发集验证召回、空结果、延迟、引用和权限/撤销污染等门禁。
4. **为客户域技能验收和受控上线准备机制。** 生产 Top-K 技能注入默认关闭；只有客户真实数据、独立判定与签名证据满足门禁时才可申请启用。

上述目标不等价于“已经支持不可信多租户生产部署”。当前安全边界是可信设备上的单本地用户；`docs/rewrite/security-threat-model.md` 已明确 Bash 不是授权边界，获得同一操作系统权限的进程仍能绕过应用层路径检查读取数据。

| 静态加密与密钥管理 | 先确定威胁模型、密钥来源、轮换、备份、恢复、审计与删除策略；使用操作系统/云 KMS 或专用服务账户做外层隔离 | 当前 SQLite 与投影对同一操作系统账号可读；应用层工具检查不是任意代码执行防护 | 密钥生命周期测试、迁移/恢复演练、权限隔离验证与外部安全评审 |
| Bash 与插件隔离 | 多租户或不可信输入部署应禁用 Bash/外部可执行插件，或为每个租户提供独立操作系统身份、容器与文件系统沙箱 | 已有动态构造路径读取 canary 的安全实验，证明字符串过滤不构成安全边界 | 容器/账户边界攻击测试、最小权限清单、工具允许列表与审计日志 |

## 7. 推荐执行顺序

1. 处理 P0 的 B1 基线常量、B2 知识并发、B3 技能性能测试稳定性，并以连续全量回归恢复本地绿灯。
2. 建立 Git 提交与远程 CI，所有后续报告均绑定 commit SHA、工作流运行 ID、数据集与实现 SHA-256。
3. 重跑 CMRC 检索、知识和发件箱门禁，作废不匹配当前实现指纹的历史报告。
4. 与目标客户共同冻结知识/技能验收数据与权限场景，执行独立验证的客户受控配对评测。
5. 在客户验收通过且安全部署边界满足后，单独评审小流量开启技能 Top-K 注入；不要把影子检索或 CMRC 指标直接等同于生产效果。
